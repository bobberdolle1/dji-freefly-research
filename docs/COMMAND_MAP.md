# Free Fly 1.0 — DUML command map

Generated by `tools/render_command_map.py` from
`research/generated/freefly_commands.json`, which is **committed**.

Every field in the table is machine-derived from bytecode and nothing
here is transcribed by hand, so the document cannot drift from the
extracted evidence.

Reproducibility differs between the two inputs:

- `freefly_commands.json` is committed, so this document regenerates
  from a clean clone with no extra setup.
- the decoded smali tree under `work/apktool/` is **gitignored**. It is
  needed only to *re-derive* the JSON, and optionally to re-verify the
  `live?` column. Rebuild with `bash tools/toolchain.sh`, then apktool
  on the sample.

The `live?` column was re-verified against the decoded smali for this
render: **all call-site counts agree** with the recorded verdicts.

## Shared defaults

Recovered from `DumlBuilder.buildPacket$default`. A **set** mask bit
means "use the built-in default", which is the opposite of how the
mask reads at a glance:

| Parameter | Default |
|---|---|
| senderType | `10` = DEV_PC |
| senderIndex | `1` |
| receiverType | `3` = DEV_FC |
| receiverIndex | `0` |
| ackType | `0` = ACK_NO_ACK |
| packetType | `0` = PKT_REQUEST |
| seqNum | `nextSeq()` (counter starts at 1) |
